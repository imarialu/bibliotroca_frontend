## 🧾Sobre
O bibliotroca é uma plataforma onde leitores podem trocar livros entre si. A aplicação foi desenvolvida para ser submetida como Trabalho final da disciplina de Tecnologia Aplicada à Inclusão Digital.

## 🌟 Objetivo
Incentivar e promover o acesso democrático e sustentável à leitura. O projeto tem como objetivo facilitar o acesso a livros em certas regiões e incentivar a reutilização por parte dos leitores.

## ⚙️ Funcionalidades
🔐 **Autenticação**
- Cadastro e Login de usuário.
- Logout da aplicação.
- Autenticação social.
- Gerenciamento da conta do usuário.
- Proteção de rotas (apenas usuários autenticados podem acessar determinadas páginas).

📖 **Gerenciamento de Livros**

- Cadastrar novos livros.
- Editar informações de um livro cadastrado.
- Marcar livro como trocado.
- Excluir livro do catálogo pessoal.
- Visualizar todos os livros disponibilizados pelo usuário.

🔍 **Exploração e Busca de Livros**

- Visualizar livros disponibilizados por outros usuários.
- Acessar os detalhes completos de um livro (título, autor, gênero, descrição, condição, dono).
- Pesquisar livros através do campo de busca.

## 🛠️ Tecnologias utilizadas
- **React + Vite**
- **Javascript**
- **Tailwind CSS**
- **PHP**
- **MySQL**
